JavaScript Tutorial

JavaScript is a versatile programming language used to create interactive and dynamic websites. Learn JavaScript step-by-step with practical examples.

Introduction to JavaScript

JavaScript is a programming language mainly used to make websites interactive and dynamic.

What is JavaScript?

HTML provides the structure of a webpage, CSS controls its appearance, and JavaScript adds behaviour and interaction.

JavaScript Example 
console.log("Hello, Brijesh!");

What can JavaScript do?

  • Change HTML content.
  • Change CSS styles.
  • Respond to user actions.
  • Validate forms.
  • Create animations.
  • Work with APIs and server data.
  • Build complete web applications.

JavaScript with HTML

index.html 
<!DOCTYPE html>

<html>

<body>

<h1 id="title">Hello</h1>

<button onclick="changeText()">
    Click Me
</button>

<script>

function changeText(){

    document.getElementById("title")
        .textContent = "Welcome to JavaScript!";

}

</script>

</body>

</html>

Why learn JavaScript?

JavaScript is one of the most important technologies for modern web development. It can be used in the browser as well as on servers through environments such as Node.js.

Remember: HTML = Structure, CSS = Design, JavaScript = Behaviour & Interaction.

JavaScript Execution

JavaScript code is executed by a JavaScript engine. Modern browsers include their own JavaScript engine.

Browser Execution 

<script>

console.log("JavaScript is running");

</script>

The browser reads the script and passes the JavaScript code to its JavaScript engine.

External JavaScript 

<script src="script.js"></script>

Node.js Installation

Node.js allows JavaScript to run outside the browser.

Check Node.js 

node --version

If Node.js is installed correctly, the command will display its installed version.

Node.js is useful when you want to build JavaScript applications on the server.

Variables in JavaScript

Variables are containers used to store data. 

let name = "Brijesh";

let age = 20;

console.log(name);
console.log(age);

Creating Variables

JavaScript commonly uses let, const and older code may use var.

Variable Naming Rules

Variable names should follow JavaScript naming rules. 

let userName = "Brijesh";

let user_age = 20;

let $price = 100;
  • Names are case-sensitive.
  • Spaces are not allowed.
  • A name should not start with a number.
  • Use meaningful names.

var vs let vs const

JavaScript provides different ways to declare variables. 

var oldWay = 10;

let score = 50;

const country = "India";

For modern JavaScript, prefer let and const depending on whether the value needs reassignment.

Data Types: Primitives and Objects

JavaScript values have different data types. 

let name = "Brijesh";     // String

let age = 20;             // Number

let active = true;        // Boolean

let value = null;         // Null

let user;                 // Undefined

let person = {
    name: "Brijesh"
};

Type Conversion & Coercion

JavaScript can convert values from one data type to another. 

let number = "25";

let result = Number(number);

console.log(result);

Operators and Expressions

Operators perform operations on values. 

let a = 10;
let b = 5;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);

Conditional Statements

Conditional statements allow code to make decisions. 

let age = 20;

if(age >= 18){

    console.log("Adult");

}

If Else Ladder 

let marks = 75;

if(marks >= 90){

    console.log("Excellent");

}else if(marks >= 60){

    console.log("Good");

}else{

    console.log("Keep Practicing");

}

Ternary Operator

The ternary operator provides a compact way to choose between two values. 

let age = 20;

let result =
age >= 18 ? "Adult" : "Minor";

console.log(result);

Switch Case 

let day = 2;

switch(day){

    case 1:
        console.log("Monday");
        break;

    case 2:
        console.log("Tuesday");
        break;

    default:
        console.log("Unknown");

}

Loops in JavaScript

Loops repeat code while a condition is satisfied. 

for(let i = 1; i <= 5; i++){

    console.log(i);

}

While Loop 

let i = 1;

while(i <= 5){

    console.log(i);

    i++;

}

Map, Filter and Reduce 

let numbers = [1,2,3,4,5];

let doubled =
numbers.map(n => n * 2);

let even =
numbers.filter(n => n % 2 === 0);

let total =
numbers.reduce((a,b) => a + b, 0);

Encapsulation

Encapsulation keeps data and methods together while controlling how data is accessed.

    #password;

}

Inheritance 

class Animal {

    speak(){
        console.log("Animal sound");
    }

}

class Dog extends Animal {

}

const dog = new Dog();

dog.speak();

Polymorphism

Polymorphism allows different objects to provide their own implementation of similar behaviour. 

class Animal {

    speak(){
        console.log("Sound");
    }

}

class Dog extends Animal {

    speak(){
        console.log("Bark");
    }

}

Abstraction

Abstraction focuses on what an object does while hiding unnecessary implementation details.

Abstraction is an important concept in object-oriented programming.

}

Errors can occur because of invalid syntax, incorrect logic or unexpected runtime conditions.
