Introduction to CSS

CSS stands for Cascading Style Sheets. It is the language used to control the appearance and layout of HTML elements.

What is CSS?

HTML creates the structure of a webpage, while CSS controls how that structure looks. With CSS you can change colors, fonts, spacing, borders, layouts and much more.

Example 
h1 {
    color: green;
    font-size: 36px;
}

Why do we use CSS?

  • To change colors and fonts.
  • To create attractive layouts.
  • To control spacing and sizing.
  • To make websites responsive.
  • To add animations and visual effects.
Remember: HTML gives a webpage structure and CSS gives that structure its visual design.

How CSS Works?

CSS works by selecting HTML elements and applying style rules to them.

Basic Process

  1. The browser reads the HTML.
  2. It finds the CSS rules.
  3. Selectors identify elements.
  4. The browser applies matching properties.
  5. The final styled page is displayed.
HTML + CSS
<h1>Hello Brijesh</h1>

h1 {
    color: blue;
}

Syntax of CSS

A CSS rule normally contains a selector, declarations, properties and values.

CSS Syntax
selector {
    property: value;
}

Example

p {
    color: red;
    font-size: 18px;
}

Here p is the selector, color and font-size are properties, and their values are red and 18px.

Ways to Add CSS

CSS can be added to an HTML document in different ways.

1. Inline CSS

<p style="color:red;">
    Hello
</p>

2. Internal CSS

<style>

p {
    color: blue;
}

</style>

3. External CSS

<link rel="stylesheet"
href="style.css">
External CSS is generally preferred for larger websites because the styles can be reused across multiple pages.

Your First CSS Website

Let's create a simple webpage using HTML and CSS.

index.html

<!DOCTYPE html>
<html>
<head>

<title>My Website</title>

<link rel="stylesheet"
href="style.css">

</head>

<body>

<h1>My First Website</h1>

<p>Welcome to my website.</p>

</body>
</html>

style.css

body {
    background: #f4f4f4;
    font-family: Arial;
}

h1 {
    color: green;
}

p {
    color: #555;
}

CSS Comments

Comments help you document your CSS without affecting the webpage.

/* This is a CSS comment */

h1 {
    color: green;
}

CSS Selectors

Selectors tell CSS which HTML elements should receive a style.

p {
    color: blue;
}

.title {
    font-size: 30px;
}

#main {
    padding: 20px;
}

CSS Specificity

Specificity determines which CSS rule wins when multiple rules target the same element.

p {
    color: blue;
}

.text {
    color: green;
}

#message {
    color: red;
}

CSS Colors

CSS supports named colors, hexadecimal values, RGB, RGBA, HSL and more.

h1 {
    color: red;
}

.box {
    background: #16a34a;
}

p {
    color: rgb(30, 64, 175);
}

CSS Backgrounds

Background properties control the background color, image, position and size of an element.

body {
    background-color: #f5f5f5;
}

.hero {
    background-image: url("image.jpg");
    background-size: cover;
    background-position: center;
}

CSS Borders

Borders can be used to visually separate or highlight elements.

.box {
    border: 2px solid green;
    border-radius: 10px;
}

CSS Padding

Padding creates space between an element's content and its border.

.card {
    padding: 20px;
}

CSS Margin

Margin creates space outside an element.

.card {
    margin: 30px;
}

CSS Box Model

Every HTML element can be understood as a box containing content, padding, border and margin.

.box {
    width: 200px;
    padding: 20px;
    border: 2px solid black;
    margin: 20px;
}

Text Styling

CSS provides many properties for controlling text appearance.

p {
    font-size: 18px;
    font-weight: 600;
    line-height: 1.6;
    text-align: center;
}

CSS Links

Links can be styled using normal, visited, hover and active states.

a {
    color: green;
    text-decoration: none;
}

a:hover {
    text-decoration: underline;
}

CSS Hover

The hover pseudo-class applies styles when the pointer moves over an element.

button:hover {
    transform: translateY(-2px);
}

CSS Cursors

The cursor property controls the pointer style.

button {
    cursor: pointer;
}

List Styles

CSS can change the marker style of ordered and unordered lists.

ul {
    list-style-type: square;
}

CSS Images

CSS can control image size, borders, object fitting and more.

img {
    width: 100%;
    max-width: 500px;
    border-radius: 12px;
}

Video Embedding

HTML provides video elements while CSS controls how the video is displayed.

video {
    width: 100%;
    max-width: 700px;
    border-radius: 10px;
}

CSS Buttons

Buttons can be styled with colors, spacing, borders and hover effects.

.btn {
    padding: 12px 22px;
    border: none;
    border-radius: 8px;
    background: #16a34a;
    color: white;
}

CSS Overflow

Overflow controls what happens when content is larger than its container.

.box {
    width: 200px;
    height: 100px;
    overflow: auto;
}

CSS Float

The float property can move an element to the left or right of its container.

.image {
    float: left;
    margin-right: 20px;
}

CSS Positioning

Positioning lets you control where elements are placed.

.box {
    position: relative;
    top: 20px;
    left: 10px;
}

CSS Z-Index

Z-index controls the stacking order of positioned elements.

.front {
    position: relative;
    z-index: 10;
}

CSS Units

CSS supports units such as px, %, em, rem, vh and vw.

.box {
    width: 80%;
    padding: 2rem;
    height: 50vh;
}

CSS Variables

CSS custom properties allow you to reuse values throughout a stylesheet.

:root {
    --primary: #16a34a;
}

button {
    background: var(--primary);
}

Maths Functions

CSS functions such as calc(), min() and max() help create flexible layouts.

.container {
    width: calc(100% - 40px);
}

CSS Forms

CSS can improve the appearance and usability of form controls.

input {
    padding: 12px;
    border: 1px solid #ccc;
    border-radius: 7px;
}

CSS Navigation Bar

Navigation bars combine links and layout techniques to help users move through a website.

.nav {
    display: flex;
    align-items: center;
    gap: 20px;
}

CSS Display

The display property controls how an element participates in layout.

.box {
    display: block;
}

.hidden {
    display: none;
}

CSS FlexBox

Flexbox is a powerful layout system for arranging elements in rows or columns.

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}

CSS Grid

CSS Grid is designed for two-dimensional layouts using rows and columns.

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

CSS Media Queries

Media queries allow a website to adapt to different screen sizes.

@media (max-width: 600px) {

    .container {
        grid-template-columns: 1fr;
    }

}

CSS Combinators

Combinators describe relationships between selectors.

.card p {
    color: green;
}

.card > p {
    font-weight: bold;
}

Pseudo-classes

Pseudo-classes style elements based on a particular state.

button:hover {
    background: green;
}

input:focus {
    outline: 2px solid blue;
}

CSS Shadows

Box and text shadows add depth to elements.

.card {
    box-shadow: 0 10px 30px rgba(0,0,0,.12);
}

Border Images

Border images allow an image to be used as a border.

.box {
    border: 10px solid transparent;
    border-image: url("border.png") 30 round;
}

CSS Gradients

Gradients create smooth transitions between colors.

.hero {
    background: linear-gradient(
        135deg,
        #16a34a,
        #2563eb
    );
}

2D Transform

Transforms can move, rotate, scale or skew an element.

.box:hover {
    transform: scale(1.05);
}

CSS Transitions

Transitions make property changes happen smoothly.

.button {
    transition: .3s ease;
}

.button:hover {
    transform: translateY(-3px);
}

CSS Animations

Animations can change CSS properties over time.

@keyframes move {

    from {
        transform: translateX(0);
    }

    to {
        transform: translateX(100px);
    }

}

.box {
    animation: move 2s infinite alternate;
}

CSS Masking

Masking can control which parts of an element remain visible.

.shape {
    mask-image: linear-gradient(
        black,
        transparent
    );
}

ToolTip Text

Tooltips provide extra information when a user points to an element.

.tooltip {
    position: relative;
}

.tooltip:hover::after {
    content: "Hello!";
    position: absolute;
}

Pagination

Pagination divides large amounts of content into separate pages.

.pagination {
    display: flex;
    gap: 8px;
}

.pagination a {
    padding: 8px 12px;
    border: 1px solid #ddd;
}

CSS Inherit

The inherit value tells an element to use the corresponding value from its parent.

.child {
    color: inherit;
}

!important Property

The !important flag increases the priority of a CSS declaration and should be used carefully.

.text {
    color: red !important;
}
Avoid using !important everywhere. Good CSS structure usually reduces the need for it.

Advanced Media Queries

Advanced media queries can respond to screen size, orientation and user preferences.

@media (min-width: 768px) and
       (orientation: landscape) {

    .layout {
        display: grid;
    }

}
